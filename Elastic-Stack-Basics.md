# Elastic Stack: The Basics — TryHackMe Elastic Stack room that introduces the ELK stack: Elasticsearch, Logstash, Beats, and Kibana, used for log analysis and SIEM-style investigations.
## What I learned: Kibana's discover tab lets you search and filter raw log data by index.
- KQL Supports logical operators like 'and, or, not' to build filters.
- Clicking a field value shows a quick breakdown of top values by percentage, useful for spotting anomalies like a dominant IP or user.
